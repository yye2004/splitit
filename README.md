# splitit

Split It is a web-based bill splitting app built with Next.js. It is designed for Malaysian receipts, including itemized orders, shared dishes, SST and rounding adjustments.

## Features

- Add multiple people to a bill
- Add itemized receipt entries
- Assign items to one or more people
- Split shared items equally
- Include service charge and rounding
- Calculate each person's final amount
- Generate a simple summary for sharing

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Local browser storage
